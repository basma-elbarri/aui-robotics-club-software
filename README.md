# AUI Robotics Club: Track A 

A Python simulation for the AUI Robotics Club Track A challenge. It calculates the shortest path for a robot navigating a grid with obstacles.

## Features
* **BFS Algorithm:** Uses Breadth-First Search to find the shortest path.
* **Multi-Leg Routing:** Handles Start -> Point A (cube) -> Point B (platform).
* **Interactive UI:** Switch map layouts, randomize obstacles, and run visual simulations.
* **Error Handling:** Detects unreachable goals.

## Run it
Make sure Python 3 is installed, then run:
```bash
python main.py
